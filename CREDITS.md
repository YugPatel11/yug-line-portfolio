# The Yug Line — Asset & Open Source Credits

This project strictly uses free, open-source, and CC0/MIT licensed assets, fonts, and libraries. No proprietary, paid, or tracking assets are used.

## 1. Typography (Open Source via Fontsource)
- **Archivo Variable**: Hector Gatti & Omnibus-Type. SIL Open Font License 1.1.
- **Manrope**: Mikhail Sharanda. SIL Open Font License 1.1.
- **IBM Plex Mono**: Mike Abbink & Bold Monday for IBM. SIL Open Font License 1.1.

## 2. Framework & Runtime Dependencies
- **Astro (v5.8.1)**: MIT License. High-performance static site generator.
- **Tailwind CSS (v3.4.17)**: MIT License. Utility-first CSS framework.
- **GSAP (v3.12.7)**: GreenSock Free Tier (used for standard accessible transforms).
- **QRCode**: MIT License (Soldair). Used for offline SVG/Canvas QR ticket generation.

## 3. Visual & Transit Assets
- **Hand-Crafted SVG Transit System**: Complete 4-car custom metro train, track geometry, and station blades authored directly in code for The Yug Line (CC0 / Unlicense).
- **Kenney Train Kit Reference Geometry**: Modular transit reference details inspired by Kenney Train Kit (Kenney.nl / CC0 1.0 Universal).
- **Poly Haven Terrazzo Surface Reference**: Architectural paver texture reference from Poly Haven (CC0 1.0 Universal).
- **Subway Tile Wall & Paper Grain Textures**: Procedural inline SVG running-bond subway tile pattern and `feTurbulence` fractal noise filter (CC0).
- **Audio Soundscape Engine**: Procedural Web Audio API sound synthesizer (brown noise, lowpass filters, stereo panners, biquad squeal filters) authored directly in TypeScript (CC0). Zero external audio file dependencies required.
